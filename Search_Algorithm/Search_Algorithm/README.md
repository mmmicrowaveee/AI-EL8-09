# 🔍 Search Algorithm (BFS & A*)

Modul ini berisi implementasi algoritma pencarian **Breadth-First Search (BFS)** dan **A* Search** menggunakan pustaka `aima-python` untuk studi kasus pencarian rute peta Romania dari **Arad** ke **Bucharest**.

---

## 📌 Algoritma yang Diimplementasikan
- **Breadth-First Search (BFS)**: Mencari rute berdasarkan jumlah langkah/kedalaman paling sedikit.
- **A* (A-Star) Search**: Mencari rute paling optimal berbasis fungsi heuristik $f(n) = g(n) + h(n)$ untuk meminimalkan total *cost*/jarak.

---

## 🚀 Cara Menjalankan (Local Execution)

```bash
cd aima-python-master
python main.py
```
